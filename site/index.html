Why it matters

Rewriting the same code does not always mean a library is missing. Sometimes a good one exists and almost nobody uses it, maybe because people don't know about it, or because writing twenty lines feels faster than adding a dependency.

Sometimes nothing fits: the existing tools do something close but not quite what apps need, so every team writes its own version. Telling those cases apart is the interesting part, and that still takes a human looking at the code.

How this was measured

The idea: if many unrelated developers write the same piece of code by hand, something may be missing — or something exists and is not being found. Nobody has to ask for the library; the code shows the need.
